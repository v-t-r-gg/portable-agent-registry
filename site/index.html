Portable Agent Registry 0.2.0

Read-only catalog of specialist self-nomad-pack-v1 snapshots. No accounts, upload API, payments, or reputation scores.

self-nomad does not host this index. hub publish writes a checked .snpack for a human pull request. hub pull runs pack --check, then install.

Index URL for self-nomad 1.4.1:

https://raw.githubusercontent.com/v-t-r-gg/portable-agent-registry/main/index.json
  • demo-echo — Repeats the operator's last sentence. Proves the pack pipe.
  • research-summarizer — Turns source notes into a short brief without personal memory.
  • code-reviewer — Reviews a diff for correctness and missing tests.

Install with self-nomad hub pull NAME --to NEW_REPO or self-nomad install ARCHIVE --to NEW_REPO, then self-nomad restore into Hermes or OpenClaw.
