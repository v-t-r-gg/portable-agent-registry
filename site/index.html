Portable Agent Registry 0.1.0

Read-only catalog of specialist self-nomad-pack-v1 snapshots. No accounts, upload, or reputation scores.

  • demo-echo — Repeats the operator's last sentence. Proves the pack pipe.
  • research-summarizer — Turns source notes into a short brief without personal memory.
  • code-reviewer — Reviews a diff for correctness and missing tests.

Install with self-nomad install ARCHIVE --to NEW_REPO, then self-nomad restore into Hermes or OpenClaw.
